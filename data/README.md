# data/

Small numerical results. Files in the top level are (re)generated by the notebooks;
`legacy/` holds data recovered from the original project whose generating sweeps
took days and were not re-run.

| file | produced by | content |
|---|---|---|
| `spider_scores_table.npy` | Notebook 01 | rows (K, classical bound, spider score, spectral gap, n̄ at N = 4000) for K = 3, 5, 7, 9. |
| `spider_codeword_photon_numbers_K3.npy` | Notebook 02 | rows (grid truncation, n̄(0_L), n̄(1_L), n̄(code)). |
| `cross_kerr_vs_drive_two_cavities.npy` | Notebook 04 | rows: drive amplitude \|Ω_d/δ_d\|², K_A, K_B, χ_AB (GHz). |
| `qin2026_cross_kerr_vs_drive_detuning.npy` | Notebook 04 | rows: δ_d/α, K_A, K_B, χ_AB (GHz), labelling overlap, for the Qin et al. 2026 parameters at \|Ω_d/δ_d\| = 1. Points with overlap < 0.93 or \|K_A\| > 1 MHz lie in the hybridised window and are not meaningful. |

## legacy/

| file | content |
|---|---|
| `SAB_plots_AqcB.npy` | shape (4, 17): drive amplitude on q_c; K_A; K_B; χ_AB (GHz) for the chain cavity A – transmon q_c – cavity B. |
| `SAB_plots_AqcBqb_qb=0.npy` | shape (4, 5): same quantities for the chain A – q_c – B – q_b with q_b undriven, vs the q_c drive. |
| `SAB_plots_AqcBqb_qc=0.09.npy` | shape (4, 8): same chain, q_c drive fixed at 0.09, vs the q_b drive. K_B crosses zero near 0.074. |
| `data_fit.pkl` | list of dicts from `misc/legacy_notebooks/self_Kerr/*.ipynb`: 4th/5th-order effective-Hamiltonian fits of a time-domain Wigner-evolution simulation vs drive amplitude (dims 15×20). |
| `KBs_blue_large_amp.pkl`, `KBs_blue_large_amp_1D.pkl` | perturbative self-Kerr K_B of cavity B on a (drive amplitude × blue detuning) grid / 1-D cut, from the same notebooks. |

Legacy parameter set (differs from the notebooks): transmon q_c with α/2π = 125 MHz,
ω_10/2π = 5.199 GHz, cavity B at 6.18 GHz, g_B/δ_B = 0.03–0.05.
