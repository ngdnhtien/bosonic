# images/

Reference diagrams used in the notes and the report. They are not produced by this
repository's code. All of them were copied into the original study notes from
Grimsmo, Combes & Baragiola, *Quantum computing with rotation-symmetric bosonic codes*,
Phys. Rev. X **10**, 011058 (2020), published under CC-BY 4.0 — credit the original authors
if you reuse them.

| file | content |
|---|---|
| `steane_knill_gadget.png` | The hybrid Steane–Knill error-correction gadget: data mode \|Ψ_N1⟩, ancilla \|Ψ_M⟩ and fresh output mode \|+_N2⟩; a CROT(φ) gate, a phase measurement (DP) and an X̄ measurement, followed by the classically controlled recovery. This is the circuit the CROT gate of Notebook 04 is for. |
| `rsb_teleportation_circuit.png` | Teleportation-based error correction for rotation codes (the same gadget in its simplest form). |
| `rsb_teleportation_T_gate.png` | Teleported T-gate circuit for rotation codes. |
| `rsb_error_propagation.png` | How a loss error on the data mode propagates through CROT into a rotation of the ancilla. |
| `rsb_modular_phase_vs_number.png` | Modular phase vs photon number: the two conjugate "distances" of a rotation code. |
| `rsb_modular_phase_measurement_example.png` | Example of a modular phase measurement on an order-4 ancilla: a loss shows up as a rotation θ_anc of the ancilla's phase. |
